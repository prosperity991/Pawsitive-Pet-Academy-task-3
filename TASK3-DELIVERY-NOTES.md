# Task 3 – Phase 1 Group: Website delivery notes

## Implemented in this website
- Responsive CSS layout for desktop, tablet and mobile screens.
- JavaScript-generated navigation with a working Explore dropdown and mobile menu.
- Course cards and a course selection / quote calculator.
- Quote breakdown table showing course, duration, fee, discount and estimated total.
- Contact form validation for name, email, optional phone number and message, with error and success messages.
- Mobile navigation closes when a link is selected or the Escape key is pressed.

## How to test
1. Extract the ZIP and open `Pawsitive-Pet-Academy/Website/index.html` in a browser.
2. Test all navigation links and the Explore dropdown.
3. Open Courses, select a course and use its quote link. Confirm the selected course is preselected in the calculator.
4. In Quote Calculator, submit with no selection, then select one, two and three courses to test the discount and results table.
5. In Contact Us, test blank/invalid name, email, phone and message values, then submit valid values.
6. Resize the browser or use mobile device emulation to test the responsive layout and menu.

## Publishing checklist
The website files are prepared for upload, but the site has **not** been published because publishing requires access to the group's hosting/GitHub account. To publish with GitHub Pages, push the project to the group's repository, open **Settings → Pages**, select the deployment branch and `/Website` folder (or move the website files to the repository root), and save. Confirm the generated public URL works.

Before public use, replace sample course information and prices, add approved contact details, and connect the contact form to a real form service. The current form demonstrates client-side validation only and does not send messages. The homepage photo is hosted by Unsplash and requires an internet connection.
