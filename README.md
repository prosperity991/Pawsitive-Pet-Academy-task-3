# Pawsitive Pet Academy — Website project

This project implements the website portion of the Task 3 / Phase 1 group brief using HTML, CSS and JavaScript. It follows the Phase 3 planning document's proposed pages and teal, warm orange, cream and charcoal-grey visual identity.

## Pages
- `Website/index.html` — Home page
- `Website/about.html` — About Us
- `Website/courses.html` — Course cards with fee, duration and selection link
- `Website/quote.html` — Course selection and quote calculator
- `Website/contact.html` — Contact/enquiry form with validation and error handling
- `Website/style.css` — Responsive styles
- `Website/script.js` — Dropdown/mobile navigation, course data, calculator and form validation

## How to run
1. Extract the ZIP file.
2. Open the `Pawsitive-Pet-Academy` folder.
3. Open `Website/index.html` in Chrome, Edge or Firefox. No build step is required.
4. Use the navigation to move between pages. Try selecting courses and calculating a quote; test the contact form with empty and valid fields.

## Quote calculator rule
Because the planning document says the discount rules must be defined but does not supply actual rates, this demo defines an example rule: 5% off for 2 courses and 10% off for 3 or more courses. Confirm and replace these rates with the group's approved rules if different.

## Before publishing
- Replace sample course details and prices with the approved information.
- Add the real academy email, telephone/WhatsApp number and exact address.
- The contact form currently validates in the browser but does not send messages. Connect a form backend/service before using it for real enquiries.
- The homepage hero photo is loaded from Unsplash and therefore requires an internet connection. Replace it with an approved local image if required.
- Publish the `Website` folder using a hosting service such as GitHub Pages or another web host.

## Important
This package contains the website, not the Android Studio/Kotlin mobile application or the Phase 2 PowerPoint presentation. Those are separate deliverables mentioned in the brief.
